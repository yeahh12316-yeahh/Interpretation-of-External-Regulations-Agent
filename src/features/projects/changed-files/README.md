# 外规解读agent

外规解读agent 是一个证据优先、人工定稿的浏览器端监管文件分析工具。它支持监管文件与官方解读分源上传，本地解析 PDF、DOCX、TXT 和扫描 PDF，通过用户自带的 OpenAI 兼容模型接口生成结构化结论，并把每项结论反向绑定到原文证据。

本产品不替代法律或合规判断。监管原文完整性、效力状态、生效日期、重大禁止事项及机构影响必须由合规人员复核。

## 本地运行

需要 Node.js 24 和 pnpm 11.19.x。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

浏览器中填写的模型 API Key 只用于当前浏览器会话。仓库、构建过程和部署平台均不配置共享模型密钥。

## 项目管理与备份迁移

所有工作以「项目（session）」为单位保存在浏览器本地（IndexedDB）。每个项目可包含多个分源材料、解析结果与分析草稿。

- **导出 / 导入**：`exportSession` 把一个项目的会话、解析结果和草稿打包为本地文件；`importSession` 在相同或另一台浏览器中还原，构成完整的迁移闭环。备份只含会话内容，凭证与原始文件不混入同一导出。
- **清单与删除**：`listSessions` 列出全部项目，`deleteSession` / `clearAllSessions` 删除单个或全部项目；删除项目会联动清除其本地留存的原始文件副本。
- **版本兼容**：会话备份带 `SESSION_BACKUP_VERSION` 与 `SESSION_BACKUP_KIND` 标记，导入时按既定版本路径校验与升级。

## 原文件本地留存（可选，默认关闭）

默认情况下，解析完成后的原始上传文件不会被保存，只保留解析结果。

如需审计可追溯性，可在上传区开启「保留原始文件副本」开关：

- 开启后，浏览器在会话旁保存一份**带 SHA-256 校验的原始字节副本**（`sessionFiles` 表），恢复项目后即可重新取回原始文件用于核验。
- 留存副本**独立于会话备份**：导出备份时仍只含会话内容，原始文件与凭证不会混进同一个导出包。
- 可通过 `verifySessionFile` 校验存储副本是否仍与原文件哈希一致。

## 断点恢复

分析过程按节点产出检查点（checkpoint），并持久化在浏览器本地（独立表，不进入会话或备份）。

- 若一次分析未跑完（浏览器关闭、刷新、意外中断），重新打开该项目会显示提示：「检测到未完成的分析：已完成 N 个节点，可从断点继续」，并提供「从断点继续分析」按钮。
- 恢复时 `runAnalysis` 会用执行计划指纹（input fingerprint）与节点清单校验检查点的有效性，仅当匹配时才续跑未完成部分。
- 检查点加载采用失败即弃（fail-closed）策略：无法解析或已过期的记录会被丢弃而不是冒险续跑，保证可重试。

## 发布前门禁

```bash
pnpm typecheck

pnpm build
pnpm scan:build
```
